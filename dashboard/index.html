Launch Radar

Protocols that still record no token, ranked by what a launch would plausibly be worth — and how to farm each one before it happens.

The model. Implied value = TVL × the median market-cap/TVL multiple of live protocols in the same category (shrunk toward the global median), adjusted for 7-day TVL momentum, for years running with no token, and for chain breadth. Every factor is printed on each protocol's page. A protocol records no token when DefiLlama carries no CoinGecko id, symbol or market cap for it; wrapped, staked and bridged products of tokens that already trade are set aside, never ranked. Values are this board's claim, not a prediction that a token will exist.

Board, values and farm plans are generated by one program from one sealed snapshot; open a protocol to see its arithmetic. Farm plans are a starting point for your own research, not financial advice: a protocol that records no token may never issue one, and nothing here is owed to any farmer.
